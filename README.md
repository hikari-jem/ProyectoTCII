PROPÓSITO

Desarrollar un dispositivo de comunicación alternativa, con el fin de disminuir la falta de comunicación en niños. El proyecto busca hacer uso de la interactividad fIsico-digital con un dispositivo IoT facilitando la comunicacion de necesidades básicas, recopilando telemetría sobre los patrones de uso e información del dispositivo.  

FUNCIONAMIENTO


CAPA 1
Mecanismo: El niño interactúa con una matriz de botones/sensores físicos con pictogramas, colores o iconos adaptados a su etapa de desarrollo (preescolar o primaria inicial).
Procesamiento: Un microcontrolador procesa la pulsación y asigna el evento a una categoría (ej. necesidades básicas, estados de ánimo, respuestas en clase o actividades).

CAPA 2
El dispositivo emite respuestas sonoras y visuales dando retroalimentación.

CAPA 3
Se lleva a cabo el registro de patrones, con cada interacción se envía de manera inalámbrica a una base de datos en la nube para registrar frecuencia, horarios y tipo de botones más utilizados.
